# 页面文案与模板测试维护

页面中的提示文案属于用户可见行为的一部分。模板测试如果断言了具体文案，文案调整必须在同一个提交中同步更新测试；否则会出现“页面正常、完整测试失败”的假故障。

## 维护规则

- 修改按钮、状态提示、空状态、更新提醒等可见文字时，先用 `rg` 搜索旧文案在模板和测试中的全部引用。
- 如果文字本身是产品约定，就同步修改对应测试断言，并在提交说明中写明新旧文案变化。
- 如果文字只是实现细节，测试优先断言稳定的 DOM id、class、`data-*` 属性或行为结果，避免对完整句子做脆弱断言。
- 两个页面共享同一交互文案时，测试应覆盖两个模板，避免只修改其中一个页面。
- 完成后至少运行相关页面测试，再运行完整测试集；完整测试失败时先确认失败断言是否仍匹配当前模板，不要为了让测试变绿而回退正确的新文案。
